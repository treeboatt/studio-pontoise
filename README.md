# Studio meublé à louer — Centre-ville de Pontoise

Site vitrine statique (HTML/CSS/JS, sans dépendance de build) pour la location du studio.

## Publier sur GitHub Pages

1. Créez un nouveau dépôt sur GitHub (public), par exemple `studio-pontoise`.
2. Ajoutez ce dépôt comme remote et poussez :
   ```bash
   git remote add origin https://github.com/VOTRE-PSEUDO/studio-pontoise.git
   git branch -M main
   git push -u origin main
   ```
3. Sur GitHub : Settings → Pages → Source → sélectionnez la branche `main` et le dossier `/ (root)` → Save.
4. Après 1-2 minutes, le site sera visible à :
   `https://VOTRE-PSEUDO.github.io/studio-pontoise/`

Aucune configuration supplémentaire n'est nécessaire : `index.html` et le dossier `images/` sont à la racine.
